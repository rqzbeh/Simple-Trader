## 1. Entities & Relational Schemas (PostgreSQL 16)

### 1.1 `admin_users`
Stores authorized administrative accounts with bcrypt-hashed credentials.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `UUID` | `PRIMARY KEY DEFAULT gen_random_uuid()` | Unique user identifier |
| `username` | `VARCHAR(64)` | `UNIQUE NOT NULL` | Administrator username |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` | Salted bcrypt hash (cost 12) |
| `role` | `VARCHAR(32)` | `NOT NULL DEFAULT 'ADMIN'` | Role (`ADMIN`, `OPERATOR`, `AUDITOR`) |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Account creation timestamp |
| `last_login_at` | `TIMESTAMPTZ` | `NULL` | Most recent login timestamp |

### 1.2 `user_sessions` (Redis 7 & PostgreSQL audit fallback)
Tracks active bearer sessions with sliding-window expiration.

| Field | Type | Description |
|---|---|---|
| `token` | `VARCHAR(64)` | Cryptographically random 256-bit hex token |
| `user_id` | `UUID` | Associated admin user ID |
| `username` | `VARCHAR(64)` | Associated username |
| `client_ip` | `VARCHAR(45)` | Client IP address (IPv4/IPv6) |
| `user_agent` | `TEXT` | Browser/device user-agent string |
| `expires_at` | `TIMESTAMPTZ` | Session expiry time (default 7 days) |

### 1.3 `encrypted_system_secrets`
Stores sensitive third-party credentials (Telegram bot tokens, private API keys) encrypted at rest via AES-GCM-256.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `key_name` | `VARCHAR(64)` | `PRIMARY KEY` | Configuration key (e.g. `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) |
| `encrypted_payload` | `TEXT` | `NOT NULL` | Base64-encoded AES-GCM ciphertext |
| `nonce` | `VARCHAR(32)` | `NOT NULL` | 12-byte initialization vector (hex-encoded) |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Last update timestamp |

### 1.4 `futures_trade_signals`
Records all two-sided trade opportunities generated by the news-catalyst engine with execution telemetry.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `BIGSERIAL` | `PRIMARY KEY` | Unique signal identifier |
| `symbol` | `VARCHAR(32)` | `NOT NULL` | Tradable pair (e.g. `BTC/USDT`, `SOL/USDT`, `XAU/USD`) |
| `direction` | `VARCHAR(8)` | `NOT NULL CHECK (direction IN ('LONG', 'SHORT'))` | Trade direction |
| `status` | `VARCHAR(16)` | `NOT NULL DEFAULT 'ACTIVE'` | Status: `PENDING`, `ACTIVE`, `CLOSED`, `CANCELLED` |
| `catalyst_headline` | `TEXT` | `NOT NULL` | The breaking news headline driving the trade |
| `catalyst_source` | `VARCHAR(64)` | `NOT NULL` | Origin source (e.g. `Whale Alert`, `Capitol Trades`, `Yahoo Finance`) |
| `catalyst_sentiment`| `DOUBLE PRECISION` | `NOT NULL` | Normalized sentiment score in $[-1.0, +1.0]$ |
| `entry_price` | `DOUBLE PRECISION` | `NOT NULL` | Recommended limit entry price |
| `stop_loss` | `DOUBLE PRECISION` | `NOT NULL` | Protective stop loss price |
| `take_profit_1` | `DOUBLE PRECISION` | `NOT NULL` | Primary take profit price ($R:R \ge 1.5$) |
| `take_profit_2` | `DOUBLE PRECISION` | `NULL` | Secondary take profit price ($R:R \ge 2.5$) |
| `leverage` | `INTEGER` | `NOT NULL DEFAULT 1` | Leverage multiplier ($1x - 10x$) |
| `risk_reward_ratio`| `DOUBLE PRECISION` | `NOT NULL` | Calculated Risk-to-Reward ratio |
| `allocated_capital_usd` | `DOUBLE PRECISION` | `NOT NULL` | Recommended position capital in USD |
| `allocated_capital_pct` | `DOUBLE PRECISION` | `NOT NULL` | Percentage of available Tier 2 Tactical Alpha |
| `exit_price` | `DOUBLE PRECISION` | `NULL` | Actual closure price |
| `exit_time` | `TIMESTAMPTZ` | `NULL` | Actual closure time |
| `exit_reason` | `VARCHAR(16)` | `NULL` | Closure trigger (`TP1`, `TP2`, `SL`, `MANUAL`) |
| `realized_pnl_usd` | `DOUBLE PRECISION` | `NULL` | Net dollar profit or loss |
| `realized_roi_pct` | `DOUBLE PRECISION` | `NULL` | Net return on invested margin percentage |
| `telegram_dispatched` | `BOOLEAN` | `NOT NULL DEFAULT FALSE` | Whether signal was broadcast to Telegram |
| `telegram_resolved` | `BOOLEAN` | `NOT NULL DEFAULT FALSE` | Whether completion was broadcast to Telegram |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Signal generation timestamp |

### 1.5 `macro_regimes`
Captures historical snapshots of macroeconomic and geopolitical scoring along with dynamic allocation targets.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `BIGSERIAL` | `PRIMARY KEY` | Snapshot ID |
| `timestamp` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Snapshot timestamp |
| `stress_score` | `DOUBLE PRECISION` | `NOT NULL` | Overall macro stress score in $[0.0, 1.0]$ |
| `geopolitical_risk_index` | `DOUBLE PRECISION` | `NOT NULL` | Conflict & war escalation score |
| `inflation_rate_pct` | `DOUBLE PRECISION` | `NOT NULL` | Active annual inflation metric |
| `interest_rate_bias` | `VARCHAR(16)` | `NOT NULL` | Central bank stance: `DOVISH`, `NEUTRAL`, `HAWKISH` |
| `target_tier1_cash_pct` | `DOUBLE PRECISION` | `NOT NULL` | Target cash buffer percentage |
| `target_tier2_alpha_pct` | `DOUBLE PRECISION` | `NOT NULL` | Target tactical alpha percentage |
| `target_tier3_core_pct` | `DOUBLE PRECISION` | `NOT NULL` | Target core preservation percentage |
| `rationale` | `TEXT` | `NOT NULL` | Economic explanation for the target split |

### 1.6 `ml_training_runs`
Maintains an immutable audit log of backend model training sessions on real market data.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `BIGSERIAL` | `PRIMARY KEY` | Training run ID |
| `symbol` | `VARCHAR(32)` | `NOT NULL` | Traded asset trained upon (e.g. `BTC/USDT`) |
| `timeframe` | `VARCHAR(16)` | `NOT NULL` | Bar timeframe (e.g. `1h`, `3h`) |
| `sample_count` | `INTEGER` | `NOT NULL` | Number of real historical candle bars trained |
| `date_start` | `TIMESTAMPTZ` | `NOT NULL` | Starting date of training dataset |
| `date_end` | `TIMESTAMPTZ` | `NOT NULL` | Ending date of training dataset |
| `training_loss` | `DOUBLE PRECISION` | `NOT NULL` | Final training loss (Log-Loss / MAE) |
| `directional_accuracy` | `DOUBLE PRECISION` | `NOT NULL` | Out-of-sample directional prediction accuracy ($0.0 - 1.0$) |
| `weights_snapshot` | `JSONB` | `NOT NULL` | Calibrated indicator and feature weights |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Run completion timestamp |

## 2. State Machine Transitions

### 2.1 Futures Trade Signal Lifecycle

```
             [News Catalyst Ingested]
                        │
                        ▼
       [Compute Technical Confluence & R:R]
                        │
              R:R >= 1.5 && News Confirmed?
               ├── No  ---> [REJECTED / HOLD]
               └── Yes ---> [ACTIVE] (Broadcast to Telegram)
                                │
          ┌─────────────────────┴─────────────────────┐
          ▼                                           ▼
   [Price hits TP1 / TP2]                     [Price hits SL]
          │                                           │
          ▼                                           ▼
   [CLOSED_PROFIT]                             [CLOSED_LOSS]
          │                                           │
          └─────────────────────┬─────────────────────┘
                                ▼
                     [Calculate Realized ROI %]
                                │
                                ▼
                  [Broadcast Summary to Telegram]
```

### 2.2 Dynamic Macro Regime Calibration

```
[Hourly Cron / Breaking Macro News]
              │
              ▼
[Extract Geopolitical Conflict & Rate Sentiment]
              │
              ▼
[Calculate Composite Stress Score S ∈ [0, 1]]
              │
      ┌───────┴───────────────────────┐
      ▼                               ▼
  S >= 0.65 (Crisis)              S < 0.35 (Expansion)
      │                               │
      ▼                               ▼
  Tier 3 (Core) -> 55-60%         Tier 2 (Alpha) -> 45-50%
  Tier 1 (Cash) -> 20-25%         Tier 3 (Core)  -> 35-40%
  Tier 2 (Alpha)-> 15-25%         Tier 1 (Cash)  -> 15%
              │                               │
              └───────────────┬───────────────┘
                              ▼
                [Update Target Allocator]
```
